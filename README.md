# Módulo de Autenticación - Feria Digital

## Descripción del proyecto
Este proyecto consiste en un módulo de registro y autenticación de usuarios desarrollado exclusivamente con tecnologías frontend (HTML, CSS y JavaScript). Implementa validaciones dinámicas, manipulación del DOM y asincronía simulada mediante Promesas.

## Instrucciones para su ejecución
Para ejecutarlo, simplemente se debe hacer doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno (se recomienda Opera o edge).
